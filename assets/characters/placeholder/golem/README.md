Attribution: Golem by umask007 (OpenGameArt), textures by yughues; original model http://www.blendswap.com/blends/view/68618

- `golem.glb`: converted copy (animations idle, walk, attack, attack2, flinch, die). `golem.tscn`: the model scene the game uses (fire texture, nearest filtering). `golem.res`: the animation library (`golem/<clip>`, idle and walk loop).
- `golem_fire.png` (default), `golem_ice.png`, `golem_stone.png`: 256 px textures; ice and stone are not used yet.
- `golem_golem_fire.png`: Godot's extraction of the glb's embedded texture (import setting); unused.
